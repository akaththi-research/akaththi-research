# Akaththi Research

Source of the Akaththi Research website. Akaththi Research studies anything
that can be measured and made to work better, in any field. It starts with
mushroom cultivation in tropical climates, to start with. Based in Chennai, India.

## What this repository is

- The static website for Akaththi Research, served by GitHub Pages.
- A place for protocols, datasets and papers once they are checked and
  ready to share.
- Not a record of unpublished findings. Nothing is published yet.

## Build the site

The pages are generated by a small script with no dependencies. Node 18 or
later is enough.

```bash
node _tools/build.mjs
```

The script writes the HTML files into the repository root. Commit the
generated files together with the source change.

| Path | What it holds |
|---|---|
| `_src/config.mjs` | Site settings: base path, canonical URL, enquiry address |
| `_src/layout.mjs` | Shared header, footer and page shell |
| `_src/pages.mjs` | The copy for every page |
| `_tools/build.mjs` | The build script |
| `assets/css/site.css` | The whole stylesheet |
| `assets/fonts/` | Self-hosted fonts and their licences |
| `assets/brand/` | Logo files for web, print and social. See its README |
| `_tools/make-brand.mjs` | Regenerates every logo size (optional, needs Playwright) |

Folders that start with an underscore are not published by GitHub Pages.

## GitHub Pages

Static files at the repository root, so no build runs on GitHub.

1. Settings, Pages.
2. Source: Deploy from a branch.
3. Branch `main`, folder `/ (root)`. Save.

The site then appears at `https://akaththi-research.github.io/akaththi-research/`.
`.nojekyll` tells Pages to serve the files exactly as they are.

## Settings to review

- **Enquiry address.** `contactEmail` in `_src/config.mjs` is empty, so the
  enquiry button opens a public GitHub issue. Set a monitored address to
  switch to email.
- **Base path.** `base` and `url` assume the project address. Change both if
  the site moves to a custom domain.
- **Licence holder.** `LICENSE` names "Akaththi Research", which is not a legal
  entity. Update it once the holder of the rights is decided.

## Writing rules for the site copy

- Say what exists, what is running and what is planned. Use the status words
  `planned`, `running`, `published` and `open`.
- No results, figures or claims until they are measured, checked and approved.
- No design details of products or their cooling systems.
