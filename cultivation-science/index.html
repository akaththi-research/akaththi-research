Questions we are asking

  • Which temperature, humidity, CO2 and light windows does each stage need, and how far can they drift before quality or yield drops?
  • Which routes bring contamination in, and which controls actually reduce it?
  • How do locally available substrates and inputs change yield and consistency?
  • What does a good record of a grow cycle look like, so one run can be compared with the next?

How we measure

  • Controlled runs with a fixed setup and logged readings.
  • Repeats before we conclude anything.
  • The same measurements across crops, so results can be compared.
  • Failed runs recorded with the successful ones.
